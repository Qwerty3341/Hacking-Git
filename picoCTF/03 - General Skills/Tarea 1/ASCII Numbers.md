## Solución 2 (Con python)
Podemos hacer una función que convierta el hexadecimal a ascii:
```python
def hex_ascii(text: str) -> str:
    # from hex to decimal
    hex_numbers = [int(x, 16) for x in text.split()]
    # from decimal to ascii
    chars = [chr(number) for number in hex_numbers]
    # join characters into a string
    string = ''.join(chars)
    return string

user_input = input('Put a string to convert from hex to ascii:\n')
print('output:')
print(hex_ascii(user_input))
```
