## Descripción
This [.tar file](https://jupiter.challenges.picoctf.org/static/52084b5ad360b25f9af83933114324e0/1000.tar) got tarred a lot.
### Hints
Try and script this, it'll save you a lot of time
## Solución
Cuando hacemos un `$tar -xf 1000.tar` Nos da un archivo `999.tar` así que viendo la pista nos damos cuenta de que son 1000 archivos .tar así que debemos hacer un script que los descomprima de manera automática.
```bash
#!/bin/bash

for ((i=1000; i>=0; i--))
do
    nombre_archivo="$i"
    
    tar -xf "${nombre_archivo}.tar"
done
```
Le damos permisos de ejecución con `chmod +x untar.sh`
```shell
-rwxr-xr-x 1 user user      112 Apr  5 00:15 untar.sh
```
Cuando lo ejecutamos se descomprimen 1000 directorios y al final nos dan un archivo `"flag.png"`. Si lo abrimos con `open` vemos una imagen con la bandera.

Bandera: `picoCTF{L0t5_0f_TAR5}`
## Notas adicionales
