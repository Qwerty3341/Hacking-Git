## Descripción
What is 0x3D (base 16) in decimal (base 10)?
## Solución 1
Usando la calculadora del sistema operativo en modo programador
- Se selecciona la opción HEX 
- Se coloca 3D
- Se ve la equivalencia en DEC
```
HEX -> 3D
DEC -> 61

picoCTF{61}
```
## Solución 2
Usando el Binary translator de [Prepostseo](https://www.prepostseo.com/)
- Se coloca Hexadecimal to Decimal
- Se coloca el numero a convertir
```
Hexadecimal to Decimal
    3D           61

picoCTF{61}
```
## Notas adicionales
 El 0x no es necesario colocarlo cuando se usa la calculadora o un traductor de números
