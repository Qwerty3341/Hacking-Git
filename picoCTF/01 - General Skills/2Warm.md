## Descripción
Can you convert the number 42 (base 10) to binary (base 2)?
## Solución 1
Usando la calculadora del sistema operativo 
- Se selecciona el tipo de calculadora "programmer"
```
42 -> 00101010

picoCTF{00101010}
```
## Solución 2
Usando el convertor de REPOSTSEO 
- Se selecciona la herramienta Binary Translator y se selecciona el tipo de conversión
```
Decimal -> Binary
  42       101010
picoCTF{101010}
```
## Notas adicionales
- También se puede usar una calculadora normal que tenga las funciones de BaseN
